# OUTPOST ODYSSEY — Junior Astronaut Mission Trainer

Version 2: a beginner-friendly hybrid web prototype for the 2026 NASA Space Apps Challenge prompt "Build a Junior Astronaut Mission Trainer".

## Run the project
1. Download and unzip `outpost_odyssey.zip`.
2. Open the `outpost_odyssey` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Choose Moon or Mars, select a crew size and start the mission.

No backend, installation, API key or database is required for this first prototype.

## Files
- `index.html` — page structure and screens
- `style.css` — responsive visual design
- `script.js` — game state, resource changes, random events and mission scoring

## Current prototype features
- Moon and Mars mission selection
- Crew-size selection
- Six resource indicators
- Five outpost actions with resource trade-offs
- Daily resource consumption
- Random mission events
- Hybrid space scene built with CSS illustration and a live Moon/Mars environment label
- Interactive emergency decision lab: solar storm, water recycling fault and power shortage
- Mission log and learning explanations
- CSS-drawn hybrid lunar/Mars outpost scene
- Interactive emergency response choices with consequences
- Rotating space science facts
- Mission score and end-of-mission report
- Responsive layout for mobile and desktop

## Important educational note
The resource values and daily consumption rates are simplified game mechanics for learning and demonstration. They are not NASA engineering specifications or real-life astronaut safety guidance. For the final challenge submission, cite reliable sources for any scientific facts you add.
